# FileManagerExplorer (FME)

**FileManagerExplorer（FME）** は、Windows向けのファイル・フォルダ管理ソフトです。

ファイルやフォルダの閲覧、コピー、切り取り、削除など、日常的なファイル管理を簡単に行えることを目指して開発しています。

## 主な機能

FMEでは、以下のような機能を提供することを目指しています。

- ファイル・フォルダの閲覧
- ファイル・フォルダのコピー
- ファイル・フォルダの切り取り
- ファイル・フォルダの削除
- ファイル管理を効率化するための操作機能
- 使いやすさを重視したGUI

## 削除機能

FMEでは、用途に応じて削除方法を選択できる設計を目指しています。

### 1. ごみ箱へ移動

通常の削除方法です。

削除したファイルをWindowsのごみ箱へ移動します。

### 2. 完全削除

Windowsのごみ箱を経由せずにファイルを削除します。

### 3. 上書き削除

ファイルの内容を上書きしてから削除する方式です。

上書き回数は1～35回の範囲で選択できる設計です。

**注意：** SSDではウェアレベリングやTRIMなどの仕組みにより、上書き削除を行っても元のデータが確実に消去されるとは限りません。

重要なデータの消去については、ストレージの種類や仕様を確認してください。

## Explorer in Explorer（EiE）

EiEは、Explorer in Explorerの略称です。

ファイル選択画面やアップロード画面などで、別のエクスプローラーを開く手間を減らすことを目的とした機能です。

小型のエクスプローラーウィンドウを表示し、通常の作業と並行してファイルを管理できる仕組みを目指しています。

## 開発方針

FMEは、日常的なファイル管理をより簡単にすることを目的として開発しています。

開発では以下の点を重視しています。

- 操作の分かりやすさ
- 不要な機能を増やしすぎないこと
- ファイル操作時の安全性
- Windowsとの親和性
- 利用者にとっての使いやすさ

## 注意事項

- ファイル操作を行う前に、対象のファイルやフォルダを確認してください。
- 完全削除や上書き削除は、通常の削除と異なり、データを元に戻せない場合があります。
- 重要なデータは事前にバックアップしてください。
- SSDでの上書き削除は、完全なデータ消去を保証するものではありません。
