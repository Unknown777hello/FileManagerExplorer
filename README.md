# FileManagerExplorer (FME)

**FileManagerExplorer（FME）** は、Windows向けのファイル・フォルダ管理ソフトウェアです。

ファイルやフォルダの閲覧、コピー、切り取り、削除など、日常的なファイル管理を効率よく行えることを目的として開発しています。

## 主な機能

FMEでは、日常的なファイル管理を効率化するため、以下の機能を搭載しています。

- ファイル・フォルダの閲覧
- ファイル・フォルダのコピー
- ファイル・フォルダの切り取り
- ファイル・フォルダの削除
- 2画面によるファイル管理
- コマンドパレットによる操作
- プレビュー機能
- その他、ファイル管理を効率化するための各種機能

## 削除機能

FMEでは、用途に応じて削除方法を選択できます。

### 1. ごみ箱へ移動

通常の削除方法です。

削除したファイルをWindowsのごみ箱へ移動します。

### 2. 完全削除

Windowsのごみ箱を経由せずにファイルを削除します。

通常の削除とは異なり、ファイルを元に戻せない場合があります。

### 3. 上書き削除

ファイルの内容を上書きしてから削除する方式です。

上書き回数は1～35回の範囲で選択できます。

**注意：** SSDではウェアレベリングやTRIMなどの仕組みにより、上書き削除を行っても元のデータが確実に消去されるとは限りません。

重要なデータの消去については、ストレージの種類や仕様を確認してください。

## Explorer in Explorer（EiE）

EiEは、Explorer in Explorerの略称です。

ファイル選択画面やアップロード画面などで、別のエクスプローラーを開く手間を減らすための機能です。

小型のエクスプローラーウィンドウを表示でき、通常のファイル管理作業と並行してファイルを操作できます。

## 開発方針

FMEは、日常的なファイル管理をより簡単かつ効率的にすることを目的として開発しています。

開発では、以下の点を重視しています。

- 操作の分かりやすさ
- 不要な機能を増やしすぎないこと
- ファイル操作時の安全性

- 利用者にとっての使いやすさ

## 注意事項

- ファイル操作を行う前に、対象のファイルやフォルダを十分に確認してください。
- 完全削除や上書き削除は、通常の削除と異なり、データを元に戻せない場合があります。
- 重要なデータは事前にバックアップしてください。
- SSDでの上書き削除は、完全なデータ消去を保証するものではありません。
